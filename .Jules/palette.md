## 2024-10-23 - Embedded Image Accessibility in Markdown Profiles
**Learning:** HTML `<img>` tags embedded in Markdown files (like GitHub profile READMEs) are frequently missing `alt` text attributes, rendering visual welcome banners or GIFs inaccessible to screen readers.
**Action:** Inspect embedded `<img>` tags in Markdown files and add descriptive `alt` attributes for screen reader accessibility.
